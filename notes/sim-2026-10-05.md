## Rules of the run
- inputs only; RAM writes limited to Options settings (text FAST, style SET, scene OFF) and naming mailbox (the game's own Code Red text entry)
- decisions from RAM reads + decomp data (collision, tile attributes, map graph) + ROM tables (moves, type chart)
