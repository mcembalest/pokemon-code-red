# Moves and battle rules (draft, 2026-10-07)

Source of truth: `models/battle/moves.mjs` (names, specs, reference answers) and `models/battle/types.mjs` (foe-type cleanup). This file is generated by `models/battle/export.mjs`.

## Battle rule
- clean the foe's bytes the way its types demand (dual type: first type's rule first) → compute what the move asks for → strike once: `await tools.<move>({ key })`, within the byte budget
- hit = right answer, one strike, under budget → FireRed applies the move as usual (crits = FireRed's own roll)
- miss = wrong answer · crash · timeout · over budget · never struck · struck twice
- naming (owner): plain technical words that sound cool; a FireRed name that is already a tech word stays (★kept); GROWL → ERRORMSG; SCRATCH → SLICE because CUT is FireRed's HM
- positions count from 0; ties → the first; "rounded down" = floor
